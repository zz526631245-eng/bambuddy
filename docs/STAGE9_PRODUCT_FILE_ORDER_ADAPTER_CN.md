# 阶段 9：产品源文件订单与虚拟打印机适配

## 本轮完成

- 订单创建优先使用“产品 + 产品源文件”；省略文件 ID 时选择该产品最新有效源文件；无源文件的产品继续走阶段 8 BOM/打印方案兼容路径。
- 订单快照保存源文件 ID、版本、库文件 ID、固定/自动摆盘策略、每盘套数、零件 ID 和兼容打印机型号。
- 自动分配器增加虚拟打印机适配层。模拟分配只记录 `virtual_printer_id`，不创建真实打印队列项，不调用 MQTT、FTP 或打印命令。
- 虚拟打印机 API 和数据库增加构建宽/深/高及每盘产能字段；A1/N2S、A2L/N9 可作为软件记录配置。

## 明确未提前完成

- 阶段 10 的真实切片、固定摆盘多盘拆分、自动复制排列和基于尺寸的产能计算尚未实现。
- 当前尺寸和产能是订单分配适配所需的持久化参数；阶段 10 才消费这些参数执行摆盘算法。
- 不能据此宣称已连接真实打印机或已完成打印。
