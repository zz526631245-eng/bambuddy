# 项目概览

本项目是在开源 Bambuddy 上增加 3D 打印农场生产管理能力。目标是让不会编程的使用者可以维护产品和零件、创建生产订单、查看每种零件还需生产多少、逐步形成打印任务，并最终通过简单的 Windows 安装包部署到其他电脑。

## 已有基础

Bambuddy 已经提供打印机通信、打印队列、文件库、服务端切片、库存、权限和虚拟打印机等能力。本项目不重做这些模块，只在它们上面增加生产业务层。

## 用户能理解的业务流程

产品 → 产品零件清单 → 每个零件的打印方案 → 生产订单 → 自动计算零件需要数量 → 人工确认打印任务草稿 → 后续阶段再调度打印机和真实打印。

其中“产品零件清单”是原路线图所称的 BOM。界面统一使用浅显中文，不向普通用户展示不必要的英文缩写。

## 当前安全边界

当前完成到阶段 8。系统只会生成未分配打印机的任务草稿，不会把任务放入原打印队列，不会联系打印机，也不会开始打印。

## 部署目标

继续沿用仓库已有 Windows 安装器和 GitHub Actions。每个发布版本从通过全部测试的 Git 标签构建，安装包包含该标签当时的代码；旧安装包不会自动包含后续修改。
