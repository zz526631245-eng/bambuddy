# 阶段 11 交接：虚拟打印、质检和清板闭环

日期：2026-08-10
分支：`codex/feature-stage11-quality-loop`

## 已完成

- 盘任务按“已分配 → 待打印 → 打印中 → 待质检 → 待清板 → 已完成”推进。
- 所有状态推进均为虚拟操作，不调用真实打印机、MQTT、FTP、队列启动或发送接口。
- 虚拟打印结束可记录“流程完成”或“打印异常”，两者都必须人工质检。
- 人工可选择全部合格、部分合格或全部失败；前端只提交合格数量，后端计算报废数量。
- 质检通过统一账本更新已安排、合格、报废和剩余数量；报废不抵扣生产需求。
- 同一操作编号可安全重放，不能重复入账；不同操作编号不能修改已经确认的质检结果。
- 清板确认前虚拟打印机保持占用，清板后等待任务才能继续分配。
- 已开始、待质检、待清板和已完成记录受到保护，不能删除或直接取消破坏历史。
- 多盘产品只有同一套全部源盘完成质检后才结算一套；重新安排使用新的产品套次编号。
- 旧数据库通过可重复执行的列迁移升级，保留已有盘任务。

## 后端接口

统一入口：

`POST /api/v1/production/plate-jobs/{id}/workflow/{action}`

动作：

- `prepare`：已分配 → 待打印
- `start`：待打印 → 打印中
- `finish`：打印中 → 待质检，需要 `machine_result=completed|failed`
- `quality`：待质检 → 待清板，需要 `good_quantity`
- `cleanup`：待清板 → 已完成并释放虚拟打印机

每次请求都必须提供唯一 `operation_id`。

## 人工验收步骤

1. 创建产品并上传源 3MF，颜色/材料与阶段 11 虚拟打印机匹配。
2. 创建生产订单，预览并确认打印任务。
3. 确认任务显示分配到“阶段11虚拟打印机”。
4. 依次点击“进入待打印”“开始虚拟打印”“模拟打印完成”。
5. 在待质检状态选择全部合格、部分合格或全部失败，核对账本。
6. 点击“确认已清板”，确认任务完成且打印机被释放。
7. 对部分失败或全部失败订单再次预览剩余数量并生成补产任务。

## 安全边界

阶段 11 不允许连接或发送到真实打印机。阶段 14 前不得解除生产队列发送保护。
